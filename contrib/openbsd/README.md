# OpenBSD — gfs

**gfs** is an HTTP service binary. This repository does not ship an
**rc** script; operators use **rc.d**-style wrappers or process supervisors as needed.

Official port skeleton: **`contrib/openbsd/port/`** (submit to **ports@openbsd.org**).

Release tarballs match **`DISTFILES`** in that port. Build locally with
**`make dist-openbsd`** from the repo root.
