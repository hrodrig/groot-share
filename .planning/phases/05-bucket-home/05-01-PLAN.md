# Phase 5 Plan 05-01 — S3 client, transit copy, retry

**Goal:** On `vps-s3`, HTTP ingest stages locally, Puts to the bucket, deletes staging; copy failure is `201` + `storage: transit` and retries. HeadBucket on `/readyz`.

**Requirements:** STOR-02, STOR-03, STOR-04, STOR-05

## Tracer

Memory blob: POST gzip → 201 `storage: s3` (or `local` on vps); fail Put → 201 `storage: transit`, staging file remains; `RetryOnce` Puts then staging is gone. Path-style options set when endpoint is set.

## Tasks

1. `internal/blob`: Store interface, Memory fake, S3 client (groot dialect + checksums WhenRequired on custom endpoint)
2. `store.Stage` / `CommitLocal`; sqlite `transit`; Ingest stays Stage+CommitLocal for `vps`
3. Server ingest on `vps-s3`: unique HTTP key, Put from staging file, success delete staging, fail SaveTransit + 201
4. `RetryOnce` + in-process loop (30s); `/readyz` HeadBucket when Blobs set
5. Tests: fake success, fake fail+retry, applyEndpoint path-style; no live bucket

## Out of scope

Prefix listing / foreign keys (05-02), retention, audit
