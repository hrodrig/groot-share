# 10-07 PLAN — Share-link admin UI (UX-09)

**Traceability:** UX-09 (share-link admin UI). Backs onto Phase 9 JSON API
(`POST/GET/DELETE /v1/archives/{id}/shares`), already shipped in v0.4.0.

## Goal

Give an admin a server-rendered way to create, copy-once, list, and revoke
time-limited share links per archive — no `curl`, no raw token re-emission.

## Tasks

### T1 — `CanShares` flag + "Share" row action (entry point)
- Add `"CanShares": ac.Can(auth.PermSharesManage)` to `shellUserData` in
  `internal/server/actor.go`.
- In `identity.go` home template: add a "Share" action between Copy-link and
  Delete in **both** the table row (`<td class="actions">`) and the card
  (`<div class="card-actions">`), guarded by `{{if $.CanShares}}`, linking to
  `/archives/{id}/shares`. Icon: a share/link node matching the existing SVG
  stroke style.
- **Verify:** viewer/uploader never see the action; admin sees it.

### T2 — Shares page (list + revoke + create form), server-rendered
- New `GET /archives/{id}/shares` (HTML) handler in `share.go`:
  - resolve archive (`ArchiveByID`); 404 if unknown.
  - `ListShareLinks(ctx, id)`; normalize each via a view struct (reuse
    `shareJSON` fields but exposed to the template as typed fields for `active`,
    `use_count`, `max_uses`, `expires_at`, `revoked_at`, `label`, `created_at`).
  - render new `sharesTmpl` (reuse `pageShell()` + `mergeActorData`; nav
    `captures`; "Back to captures" link; archive key in the heading).
- The page has three regions:
  1. **Create form** — preset TTL buttons (`24h`, `7d`) that set
     `expires_in` via a tiny inline script; custom `<input type="datetime-local">`
     (`expires_at_local`); optional label; optional `max_uses` (number, min 0).
     Submits `POST /archives/{id}/shares` (form-encoded).
  2. **Active links table** — label, created (UTC), expires (UTC), uses
     (`use_count`/`max_uses`, "∞" when max 0), status pill (active/expired/
     revoked), and a Revoke button (form POST to the revoke alias).
  3. **Notice flash** — same `.notice` primitive as the rest of Phase 10.

### T3 — Create handler (form) + copy-once
- `POST /archives/{id}/shares` handler detects form-encoded (mirror
  `isBrowserForm`/`wantsJSON` split used by upload/delete):
  - **JSON path** (existing `handleCreateShare`) stays unchanged for API clients.
  - **Form path**: parse `expires_in` / `expires_at_local` / `label` / `max_uses`,
    apply the **same** validation as the JSON path (exactly one of `expires_in`
    vs absolute expiry, `max_uses >= 0`, expiry in the future relative to UTC).
  - On success: create the link, then **render the shares page directly (200)**
    with the full URL + raw token embedded once in the response body
    (`data-copy-url` + visible text) under a `notice=created` block. **No 303,
    no query-string token.**
  - On validation failure: render the page again with `notice=error` and echo the
    submitted values so the operator can correct without losing input.
- The raw token never appears in a URL, a header, or the access log path.

### T4 — Revoke handler (form alias) + typed-name confirm
- Add a revoke form alias so the HTML form can fire it: `POST
  /v1/archives/{id}/shares/{share_id}/revoke` (or accept `POST` with trailing
  `/revoke`), matching the existing `handleDelete` `/delete` suffix convention.
  It calls the same `RevokeShareLink` logic as the JSON `DELETE` and redirects
  back to `/archives/{id}/shares?notice=revoked` (this 303 path carries no token).
- Wire the confirm dialog to the revoke form via `data-confirm` +
  `data-confirm-require` (typed label) so revoking is explicit.

### T5 — CSS + copy feedback
- Add `shares`-page CSS to `layoutCSS` (minimal; reuse `.card`, `.field`,
  `.btn`, `.notice`, `.pill`). One small `.share-url` block for the copy-once
  URL (mono, word-break, copy button) and the existing `copy-link` JS hook
  (`data-copy-url`) for the copy button — no new JS beyond the preset helper.
- Confirm `misspell` (US English): `max uses`, `revoked`, `expires`, `created`.

### T6 — Tests
- `TestSharesPage` — admin GET renders create form + lists links; viewer/anon
  forbidden (redirect/403); unknown archive 404.
- `TestSharesCreateForm` — happy path returns `200` with the URL **once** in the
  body and **never** in `Location`/path; invalid TTL (both/past/negative max)
  fails closed with `notice=error`; label + `max_uses` round-trip.
- `TestSharesRevokeForm` — revoke redirects with `notice=revoked`; link absent
  from list afterward; revoking an already-unknown id 404s.
- Ensure `go build ./...`, `gofmt`, and `make ci` green.

## Out of scope (restated)
- No change to the Phase 9 JSON API or `/s/{token}` download behavior.
- No pagination on the shares list; no producer-origin; no analyze/redaction.

## Definition of done
- Admin sees "Share" on captures, creates a link with a preset/custom TTL, copies
  the URL once, lists and revokes it; raw token appears exactly once and never in
  logs/URLs; non-admins cannot reach it; `make ci` green; SPEC/CHANGELOG/README/
  SUMMARY/STATE/ROADMAP updated.
