# Plan 10-01 — Captures dashboard (summary strip, primary CTA, newest-first, pin strip)

**Phase:** 10 — Operational catalog UX
**Goal:** Turn `/` (Captures) from "list + stats line" into the **incident
evidence locker** entry point. Operator lands here, sees the shape of the
inventory, can upload in one click, can pin archives they keep coming back to.

**Locked in 10-CONTEXT.md (D-01..D-16):** vanilla HTML, server-rendered, no SPA;
color tokens already exist (`--accent/--ok/--warn/--err`); product chrome already
shows `gfs v{VERSION}`; `statsLine()` already provides `N archives · X total`.

**Tracability:** UX-01 (Captures dashboard) primary; touches UX-06 (state tokens
audit) and UX-09 layout shape (plan 10-07 will reuse the row action slot).

## Tasks

### T1 — `archive_pins` schema + store layer

**Files**
- `internal/store/schema.go` — append migration
- `internal/store/pins.go` — new file
- `internal/store/pins_test.go` — coverage

**Schema**
```sql
CREATE TABLE archive_pins (
  user_id INTEGER NOT NULL,
  archive_id TEXT NOT NULL,
  archive_key TEXT NOT NULL,
  archive_size INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  PRIMARY KEY (user_id, archive_id),
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
CREATE INDEX idx_archive_pins_user ON archive_pins(user_id, created_at DESC);
```

Bump schema version per existing migration pattern (check `migrate_test.go`
before changing). Migration must be **additive** and **idempotent**.

**Store API**
- `AddPin(ctx, userID int64, a store.Archive) error` — `INSERT OR IGNORE`
- `RemovePin(ctx, userID int64, archiveID string) (bool, error)` — returns
  `removed=true` if a row was deleted
- `ListPins(ctx, userID int64, limit int) ([]store.PinnedArchive, error)` — joins
  nothing; snapshots `archive_key` + `archive_size` at pin time so render works
  even when the archive is in transit (vps-s3) or was deleted (orphaned pin =
  shown as struck through, hidden in 10-01 v1)
- `PinnedArchive` struct in `internal/store/types.go` (extend) or inline

**Tests** (`pins_test.go`)
- Add then List shows it
- Add twice → still one row (idempotent)
- Remove twice → second returns `removed=false, nil`
- Two users, same archive → both have their own pin
- Cascade on user delete (FK)

**Verification:** `gofmt -l` clean, `go test ./internal/store/...` green,
`golangci-lint run` clean.

### T2 — Pin endpoints

**Files**
- `internal/server/pins.go` — new
- `internal/server/pins_test.go`
- `internal/server/server.go` — register routes (check existing pattern)

**Routes**
- `POST /v1/archives/{id}/pin` — any authenticated user (viewer/uploader/admin)
  succeeds; 404 if archive id unknown to this user
- `DELETE /v1/archives/{id}/pin` — idempotent, 204 No Content
- `GET /v1/archives/pins` — JSON list (for future client; **defer UI for 10-01**)
  to keep dashboard commit small

**RBAC:** session cookie or any valid api_key. Use existing auth middleware;
viewer is enough to pin (it's a personal preference, not destructive).

**Audit:** **no** audit row for pin / unpin — it is a UI affordance, not an
evidence event. Document in CONTEXT deferred if asked.

**Tests**
- POST creates row
- POST again is idempotent (200, not 201 on repeat? or 201 both — pick 201 + idempotent body)
- DELETE 204
- DELETE when not pinned still 204
- Non-existent archive id → 404
- Anonymous → 401

**Verification:** routes appear in `GET /healthz` smoke; `go test ./internal/server/...` green.

### T3 — Captures summary strip

**Files**
- `internal/server/identity.go` — modify `homeTmpl` only
- `internal/server/archives.go` — extend `handleHome` to compute summary
- `internal/server/html.go` — add `.summary` CSS
- `internal/server/html_test.go` — render assertions

**Data shape** added to `data` map in `handleHome`:
- `Summary` (struct): `Count int`, `Bytes int64`, `ClusterCount int`,
  `IncompleteCount int`, `StorageTopology string`

`ClusterCount` for 10-01: **best-effort filename parse** with a small helper
in `internal/store/name.go` (parse `<prefix>-<ts>-<cluster>[-since-...].tar.gz`,
extract cluster slug). When parse fails → bucket as `"(unparsed)"`. The full
parse + chip rendering is **plan 10-02**; here we just need the **count of
distinct cluster slugs** (placeholder for the dashboard).

`IncompleteCount`: items where `Storage == "transit"`. Cheap; no manifest peek
needed for 10-01.

`StorageTopology`: derived from `s.Cfg.Topology` (`"vps"` or `"vps-s3"`).

**Render** (vanilla HTML inside `homeTmpl`):
```html
<section class="summary card" aria-label="Inventory summary">
  <div class="summary-cell"><span class="num tabular">{{.Summary.Count}}</span><span class="lbl">captures</span></div>
  <div class="summary-cell"><span class="num tabular">{{humansize .Summary.Bytes}}</span><span class="lbl">on disk</span></div>
  <div class="summary-cell"><span class="num tabular">{{.Summary.ClusterCount}}</span><span class="lbl">clusters</span></div>
  <div class="summary-cell"><span class="num tabular">{{.Summary.IncompleteCount}}</span><span class="lbl">in transit</span></div>
  <div class="summary-cell summary-topo"><span class="pill pill-{{.Summary.StorageTopology}}">{{.Summary.StorageTopology}}</span></div>
</section>
```

Empty state: when `Count == 0` the strip is **still rendered** (so the operator
sees "0 captures · 0 B on disk · VPS" instead of an empty page).

**CSS** (add to `layoutCSS`):
```css
.summary { display: flex; flex-wrap: wrap; gap: 0; padding: 0; overflow: hidden; }
.summary-cell { flex: 1 1 8rem; padding: 16px 20px; border-right: 1px solid var(--line); }
.summary-cell:last-child { border-right: 0; }
.summary-cell .num { display: block; font: 650 22px/1.2 var(--sans); color: var(--ink); }
.summary-cell .lbl { display: block; margin-top: 4px; font: 600 11px/1 var(--mono); text-transform: uppercase; letter-spacing: 0.06em; color: var(--muted); }
.summary-topo { display: flex; align-items: center; justify-content: center; }
```

**Tests** (render)
- 0 archives → strip shows `0 / 0 B / 0 / 0 / vps`
- 3 archives mixed topology → correct numbers
- Cluster count distinct from basenames
- Transit row → IncompleteCount > 0

**Verification:** `gofmt`, `go test`, `golangci-lint`; manual `make run` + visit
