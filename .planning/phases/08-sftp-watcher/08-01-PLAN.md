# Plan 08-01: SFTP inbox watcher — ingest + source=sftp

**Phase:** 8 — SFTP inbox watcher
**Depends on:** Phase 7 (RBAC) recommended — same delete/list matrix applies
**Requirement:** ING-04

## Goal

When `GFS_SFTP_INBOX` is set, gfs polls the directory, ingests stable `*.tar.gz` files with `source=sftp`, and removes them from the inbox on success.

## Tasks

1. **Config** — `GFS_SFTP_INBOX`, `GFS_SFTP_POLL` (default `30s`) in `internal/config`
2. **Store refactor** — `CommitLocal(ctx, st, source string)`; `Ingest` keeps `http`; new `IngestFromFile(ctx, path, key, source, uploadedBy)` or watcher calls Stage+Commit with `sftp`
3. **Watcher** — `internal/server/watch.go`: `WatchOnce`, `WatchLoop`; stable-size map; only `.tar.gz`
4. **Catalog** — `ingestSFTPFile` reuses transit path on `vps-s3` with `blob.SFTPKey`; set `Archive.Source = "sftp"`
5. **blob/key.go** — `SFTPKey(prefix, id, t)` → `{prefix}sftp/{yyyy}/{mm}/{dd}/{32hex}.tar.gz`; `SourceForKey` returns `sftp` for that pattern
6. **main.go** — `go app.WatchLoop(ctx, cfg.SFTPPoll)` when inbox non-empty
7. **Audit** — `recordSFTPAudit(action upload)` with actor `sftp`
8. **Tests** — temp inbox dir; drop file; `WatchOnce` → row in sqlite with `source=sftp`; duplicate removes inbox file; vps-s3 fake blob gets `sftp/` key
