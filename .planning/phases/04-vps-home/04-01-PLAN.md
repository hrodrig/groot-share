# Phase 4 Plan 04-01 — Local blob + upload API

**Goal:** Stream `POST /v1/archives` to disk; list JSON; download by id.

**Requirements:** ING-01, ING-03, STOR-01, LIST-02 (API)

## Tracer

Authenticated POST of a small gzip body → 201 `{id,key,size,sha256,source:http}`; GET `/v1/archives` includes it; GET `/v1/archives/{id}` returns the same bytes.

## Tasks

1. `archives` table + `{dataDir}/home` + `{dataDir}/staging`
2. Stream copy + sha256; rename into home; insert row
3. Routes POST/GET `/v1/archives`, GET `/v1/archives/{id}` and `.../file`
4. Tests: upload, list, download, 401, MaxBytesReader

HTML (04-02), S3
