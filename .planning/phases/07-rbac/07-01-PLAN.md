# Phase 7 Plan 07-01 — RBAC core + route enforcement

**Goal:** Every archive/audit route checks role or api_key scope. api_key no longer acts as full session. Schema migrated from `admin` flag to `role`.

**Requirements:** AUTH-05 (partial), closes 999.1 M-3

**Depends on:** Phases 1–6 complete

## Tracer

Migrate DB: old `admin=1` → `role=admin`, `admin=0` → `role=uploader`. Viewer user gets 403 on upload. api_key with scope `upload` gets 403 on download. Admin session can delete; uploader session gets 403 on delete.

## Tasks

1. **SPEC amend** — `docs/SPECIFICATIONS.md`: add §6.1 Roles; move RBAC out of v0.1 non-goals; document api_key scopes in §4.
2. **`internal/auth/perm.go`** — `Role` type, `Permission` constants, `Can(role, perm, AuthMethod, KeyScope) bool`.
3. **Schema migration** in `internal/store`:
   - `users.role`, `users.active`
   - `api_keys.scope`
   - migrate from `admin` column; bump user_version
   - update `User` struct: replace `Admin bool` with `Role Role`
   - `EnsureAdmin` sets `role=admin`
4. **`actorFromRequest`** — return auth method + key scope; reject inactive users.
5. **`requirePermission(perm)`** — replace bare `requireAuth` on:
   - `POST /v1/archives` → `archives:write`
   - `GET /v1/archives`, `GET /v1/archives/{id}`, `GET /`, download → `archives:read`
   - `DELETE|POST .../delete` → `archives:delete` (session admin only)
   - `GET /v1/audit` → `audit:read`
   - `POST /v1/users`, future user routes → `users:manage`
   - `POST /v1/api-keys` → `apikeys:manage` (role-gated scope)
6. **Templates** — hide Delete button unless actor is admin (session).
7. **Tests** — table-driven matrix (minimum 12 cases); migration test with legacy `admin` column fixture.
