# Phase 2 Plan 02-01 — Config, slog, healthz/readyz

**Goal:** `gfs` starts only with a valid topology, logs slog JSON on stdout, and answers `/healthz` + `/readyz`.

**Requirements:** AUTH-04, OPS-01, OPS-02, OPS-03

## Tracer

With `GFS_TOPOLOGY=vps` and `GFS_DATA_DIR` = a temp dir, `GET /healthz` is 200 and `GET /readyz` is 200. `GFS_TOPOLOGY=s3` makes `LoadFromEnv` return an error (process would exit 1).

## Tasks

1. **`internal/config`** — `LoadFromEnv()`:
   - `GFS_LISTEN` default `:8080`
   - `GFS_TOPOLOGY` required: `vps` \| `vps-s3`; missing/`s3`/other → error
   - `GFS_DATA_DIR` required
   - `GFS_LOG_FORMAT` default `json`, `GFS_LOG_LEVEL` default `info`
   - `vps-s3`: require `GFS_S3_BUCKET`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`; optional endpoint/region/prefix/path-style per CONTEXT D-04
   - Table tests: refuse `s3`, missing topology, missing data dir, missing bucket on `vps-s3`; accept `vps`
2. **`internal/logging`** — copy trigger prefix writer; prefix `gfs `; default writer **stdout**; `SetupWriter` for tests
3. **`internal/store`** — open `{DataDir}/gfs.db` via `modernc.org/sqlite`, `Ping`/`SELECT 1`, `Close`. `MkdirAll(DataDir, 0750)` before open. No schema.
4. **`internal/server`** — stdlib mux: `GET /healthz` → 200 `ok\n`; `GET /readyz` → 200/503 from a `Ready func() bool`; access log skips probes. No other routes.
5. **`cmd/gfs`** — keep version flags; bare invoke: `LoadFromEnv` (stderr + exit 1 on error) → logging.Setup → open store → listenAndServe (copy trigger SIGTERM). Wire `Ready` to store ping (+ vps-s3 env still set).
6. **Tests** — httptest healthz 200 without env secrets; readyz 503 when Ready false; config fail-closed; logging JSON-ish line. `make test` / `make ci` green; coverage ≥ 60.

## Verify

- `GFS_TOPOLOGY=s3` → `LoadFromEnv` error
- `vps-s3` without bucket/creds → error
- `GET /healthz` 200 unauthenticated
- `GET /readyz` 200 with open sqlite; 503 if Ready false
- slog JSON on stdout (test via `SetupWriter`)
- `make ci` green

## Out of scope

Login, api_key, upload/list, AWS SDK / HeadBucket, retention env, trusted proxies
